# UC-AUTH-02 — DESIGN-README (Quên mật khẩu)

- Hộp thoại `Sheet` trượt lên trên điện thoại, giữa màn trên máy tính; tiêu đề "Quên mật khẩu", một câu giải thích, ô email, nút chính "Gửi liên kết", nút phụ "Huỷ".
- Đang gửi: spinner trong nút. Lỗi: dưới ô email, `aria-invalid`, `role="alert"`.
- Esc đóng, trả tiêu điểm về liên kết "Quên mật khẩu".
